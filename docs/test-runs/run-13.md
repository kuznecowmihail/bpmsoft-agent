# Задачи для проверки — прогон 13 (история чатов)

Проверяем панель чатов слева: после перезапуска приложения прежний чат открывается из списка и продолжается с полным контекстом агента; чаты видны только для текущего стенда; провайдер и модель переключаются на те, что были в чате; чаты, которые продолжить нельзя, открываются только для чтения.

## Перед прогоном
- Собери и перезапусти приложение: `npm run build -w @bpmsoft-agent/agent-runtime`, затем `npm run dev -w @bpmsoft-agent/desktop` (или собранное приложение).
- Заданы оба ключа: Claude и Cursor.
- Стенд — отдельный тестовый пакет `<Пакет>`. Агенту даём только задачи на чтение, схемы не создаём.
- Во время прогона не запускай эвалы и не обновляй стенд из других окон: стенд общий.
- Логи: `~/Library/Logs/bpmsoft-agent/chats/<дата>/` (macOS) или `<userData>/logs/chats/<дата>/` (Windows); индекс — `chats/index.json` там же.

## Что смотреть во всех задачах
1. Слева — список чатов только текущего стенда, новые сверху; у каждого название, время и бейдж «Claude»/«Cursor».
2. Открытие чата из списка ничего не запускает: нет хода агента, нет запросов к CRM и БД.
3. Продолжение пишет в тот же `.jsonl`/`.md`, новый файл в папке дня не появляется.
4. Пока агент работает, список и «Новый чат» неактивны.

---

## 1. Продолжение после перезапуска (Claude)
**Формулировка:** «Найди в `<Пакет>` все схемы объектов и перечисли их с заголовками». Дождись ответа. Закрой приложение и открой снова, открой тот же стенд.
**Проверяет:** восстановление ленты и `resume` сессии Claude.
**Как проверить:**
- чат первый в списке, после клика лента такая же, как до перезапуска;
- спроси «Какие схемы ты нашёл в прошлом ответе? Ничего не читай заново» — агент перечисляет их по памяти, без вызова инструментов;
- в `.jsonl` у нового `user_message` поле `resume` равно `sessionId` прежнего `system_init`; новый `system_init` несёт тот же id.

## 2. Продолжение после перезапуска (Cursor)
**Формулировка:** как в задаче 1, провайдер Cursor.
**Проверяет:** переживает ли агент Cursor перезапуск приложения (`Agent.resume`).
**Как проверить:**
- то же, что в задаче 1;
- если вместо ответа появилась ошибка «Контекст чата не восстановлен…», а чат в списке стал бледным и только для чтения — защита сработала правильно, но Cursor не восстанавливает сессию после перезапуска. Запиши это в итог прогона: тогда чаты Cursor из прошлых запусков нужно сразу открывать только для чтения.

## 3. Переключение провайдера и модели
**Формулировка:** в ⚙ выбери Claude с какой-нибудь моделью, затем открой из списка чат Cursor из задачи 2.
**Проверяет:** при открытии чата провайдер и модель переключаются на его.
**Как проверить:**
- бейдж провайдера в шапке сменился на Cursor с моделью чата;
- открой чат Claude из задачи 1 — шапка вернулась на Claude с его моделью;
- «Новый чат» после этого идёт на провайдере, выбранном последним.

## 4. Чат без ключа — только чтение
**Формулировка:** в ⚙ удали ключ Cursor, открой чат Cursor.
**Проверяет:** чат без ключа провайдера не продолжается и не ломает настройки.
**Как проверить:**
- вместо поля ввода текст «Не задан ключ Cursor — продолжить чат нельзя…»;
- провайдер в шапке не сменился;
- «Новый чат» работает как обычно. После проверки верни ключ.

## 5. Только текущий стенд
**Формулировка:** «Сменить проект» → открой другой стенд (или другую папку `Pkg`).
**Проверяет:** фильтр по стенду.
**Как проверить:** чатов из задач 1–4 в списке нет; вернись на первый стенд — они на месте.

## 6. Перезапуск во время хода
**Формулировка:** «Подробно опиши все схемы `<Пакет>`: прочитай каждую». Пока агент читает файлы, закрой приложение. Открой снова, открой этот чат и напиши «продолжай».
**Проверяет:** пометку о прерванном ходе.
**Как проверить:**
- в `.jsonl` у нового `user_message` поле `afterInterrupt: true`;
- агент сначала сверяется с тем, что успел сделать, а не начинает с нуля.

## 7. Старые чаты
**Формулировка:** удали `chats/index.json` и перезапусти приложение.
**Проверяет:** индекс пересобирается из логов.
**Как проверить:** в списке появились и чаты, созданные до этой версии приложения, с названиями по первому сообщению.

## Итог
- После прогона предложи прогнать эвалы по любой теме один раз: изменился текст хода после прерывания (пометка `INTERRUPTED_TURN_NOTE`).
