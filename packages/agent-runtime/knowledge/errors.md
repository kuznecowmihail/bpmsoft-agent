# Ошибки компиляции, загрузки и выполнения — сводка

Известные ошибки: текст → причина → что делать. Это указатель на ✅-факты; подробности и даты подтверждения — в файле из последней колонки. Где искать текст ошибки: компиляция — ответ компиляции и `Build.log`; «Обновить из файловой системы» — строки `Exception:` в `[app]/Logs/<ГГГГ-ММ-ДД>/PackagesSynchronization.log`; выполнение — `Error.log` и `Common.log` той же папки (время — UTC).

## Компиляция

| Ошибка | Причина | Что делать | Подробно |
|---|---|---|---|
| `CS0246` на `LocalizableString` | тип в `BPMSoft.Common`, а не в `BPMSoft.Core` | `using BPMSoft.Common;` | `source-code-edit.md`, `platform-api.md` |
| `CS0246` в `<Процесс>MethodsWrapper` на класс пакета | код задания-сценария (`CH1`) компилируется в `namespace BPMSoft.Core.Process` | полное имя `BPMSoft.Configuration.<Класс>` или `BPMSoft.Configuration` в `B3` | `process-edit.md` |
| `CS0103` на имя элемента процесса в задании-сценарии | элементы процесса — не переменные C# | значение через параметр процесса или `Get<T>("<Элемент>.<Параметр>")` | `process-data-edit.md`, `web-service.md` |
| `CS0117: 'SysSettings' does not contain a definition for 'GetValue'` | в `namespace BPMSoft.Configuration` короткое `SysSettings` — сгенерированный класс объекта | `global::BPMSoft.Core.Configuration.SysSettings` | `platform-api.md` |
| `CS0576`: конфликт с псевдонимом `SysSettings` | псевдоним объявлен внутри `namespace BPMSoft.Configuration` | полное имя или псевдоним во вложенном пространстве имён | `source-code-edit.md` |
| «Argument 3 must be passed with the 'out' keyword» | `SysSettings.TryGetValue` вызван с `ref` | `out object value` | `platform-api.md` |
| `CS0311` в `Autogenerated/Src/<Объект>Schema.<Пакет>.cs` | родитель объекта замещён в пакете вне зависимостей пакета наследника | зависимость пакета, затем `ModifiedOnUtc` у затронутых схем, обновление и компиляция | `entity-edit.md`, `metadata-editing.md` |
| ошибка в схеме, которую не правили | компилируется вся конфигурация | иди по файлу и строке из ответа; чужую ошибку назови пользователю | `metadata-editing.md` |

## «Обновить из файловой системы»

| Ошибка | Причина | Что делать | Подробно |
|---|---|---|---|
| «Значение аргумента "descriptor" не может быть пустым», «Некорректный дескриптор…» | общий текст, причина — в журнале | строки `Exception:` в `PackagesSynchronization.log` | `metadata-editing.md` |
| `FormatException: The input string '' was not in a correct format` (в журнале — `ConvertUtilities.StringToPoint`) | дробная координата `BL3`, `CI11`, `CI12` в процессе | только целые числа | `process-edit.md` |
| `InvalidDescriptorInFileSystemException: Название объекта "<имя>" некорректное` | посторонняя папка в `Schemas` или в папке схемы | удали папку | `metadata-editing.md` |
| «У колонки "<Колонка>" не указана ссылка на справочник» | унаследованная колонка-ссылка не переопределена | переопредели колонку | `entity-edit.md`, «Иерархический справочник» |
| `42809: referenced relation "<Имя>" is not a table` | ссылка на представление без `E8` | `E8` у колонки | `entity.md`, «Ссылка на пользователя и на представление» |
| `Unable to cast object of type 'System.String' to type 'System.DateTime'` | пустой или неверный `ModifiedOnUtc` | `date +%s000` в `descriptor.json` | `metadata-editing.md` |
| `An item with the same key has already been added` | `Get<Entity>("<Элемент>.ResultEntity")` и та же колонка в условии шлюза | значение через параметр процесса | `process-data-edit.md` |
| `InvalidCastException: … 'System.Int64' to type 'System.String'` в наборе данных правил прав | колонки `Operation`, `RightLevel` в БД — числа | SQL-скрипт пакета | `rights.md`, `rights-edit.md` |
