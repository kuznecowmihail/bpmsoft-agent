# Процессы: страницы пользователю (UserTask) и преднастроенные страницы — факты

Как устроены элементы-страницы процесса в metadata. Общее о процессах — `processes.md`; рецепты элементов — `process-tasks-edit.md`; свои действия процесса — `user-task.md`.

## UserTask — страницы и «преднастроенные страницы»
- Обычный `UserTask` (например `EmailSendUserTask`) — поле `J6` напрямую ссылается на UId существующей клиентской схемы (реальной страницы). `BL7` здесь ТОЖЕ варьируется по экземпляру (в отличие от `ScriptTask`/`Timer`, где `BL7` — фиксированная константа типа элемента, см. раздел «Структура файла» выше).
- «Преднастроенная страница» (**подтверждено скриншотом**: правая панель Designer называется буквально «Преднастроенная страница») — распознаётся по полю `J5: "ProcessUserTaskSchemaManager"`. В этом режиме `BL7` и `J6` совпадают друг с другом и указывают на **внутренний виртуальный UId** (не физическая схема — файла `descriptor.json` с таким UId не существует), а реальная целевая страница лежит в отдельном именованном параметре `ClientUnitSchemaUId` внутри `BP2` (**подтверждено самопроверкой**: значение `ClientUnitSchemaUId.L8.GS2` точно совпало с UId страницы, открытой в Designer).

- Другие полезные параметры внутри `BP2` преднастроенной страницы: `EntitySchemaUId`+`EntityId` (объект и запись привязки), `OwnerId` (кто выполняет — подтверждено скриншотом: `[#SysVariable.CurrentUserContact#]` = «Контакт текущего пользователя»), `ShowExecutionPage` (булево, вероятно = «Показывать страницу автоматически»), `UseCardProcessModule` (булево, назначение не установлено), `Title`/`Recommendation`/`InformationOnStep` (текстовые подписи страницы).
- `BO2` — присутствует и равен `true` только у преднастроенных страниц (гипотеза: флаг «это преднастроенная страница»).
- `BO3` — **полностью подтверждено широким сканированием** (14039 элементов всего проекта): 100%-е чистое разделение — присутствует (`true`) на АБСОЛЮТНО ВСЕХ элементах-узлах (события, задачи, шлюзы), отсутствует на АБСОЛЮТНО ВСЕХ связях (`SequenceFlow`/`ConditionalFlow`). Это структурный маркер «это узел диаграммы, а не линия», а не бизнес-настройка — вопрос закрыт.
