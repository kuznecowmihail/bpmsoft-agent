# Регистрация разделов, карточек, мини-карточек и деталей — рецепты
Модель записей — `registration.md`. Общий формат Data-наборов — `data.md`/`data-edit.md`. Правила из `metadata-editing.md` действуют: актуальный `ModifiedOnUtc` в каждом `descriptor.json`, локализация на ru-RU и en-US.

## ✅ Общий порядок (проверен на разделе `TestColumns`, деталь, мини-карточка — см. разделы ниже)
1. Для каждой нужной таблицы создай папку `Pkg/<Пакет>/Data/<Имя набора>/` с файлами `descriptor.json`, `data.json`, пустым `filter.json` и, если у таблицы есть локализуемые колонки, `Localization/data.ru-RU.json` и `data.en-US.json`.
2. `descriptor.json` не собирай вручную: скопируй с реального набора той же таблицы из любого пакета проекта (найди в `Pkg/*/Data/` набор с таким же префиксом имени, например `SysModuleEntity_*`), поменяй `UId` набора, `Name`, `ModifiedOnUtc`. Список `Columns` оставь как в образце — в `data.json` должны быть значения ровно этих колонок.
   - ✅ Образца в проекте нет (подтверждено в CRM, 08.10.2026, проект без своих пакетов): возьми готовый набор из `templates/data/` или собери `descriptor.json` сам — UId колонок из `Autogenerated/Src/<Таблица>Schema.*.cs`, GUID типов из `[app]/Resources/ui/BPMSoft/core/enums/sysenums.js`. Так собраны и установились наборы `Lookup`, `SysModuleEntity`, `SysModule`, `SysModuleEdit`, `SysModuleInWorkplace`, `SysDetail`, `SysImage`, `SysSettings`, `SysSettingsValue`.
3. Новые `Id` записей — новые GUID. Ссылки между записями — по этим `Id` (см. порядок ниже).
   - У lookup-колонок (`SysModuleEntity`, `SysWorkplace`, `SysModule`, `FolderMode`, `Image32` и т.д.) в `data.json` обязательно поле `DisplayValue` (отображаемое значение или `"null"`) — иначе установка набора падает с ошибкой «При попытке чтения свойства "DisplayValue" получено значение ""». ✅ Проверено.
4. UId схем бери из `descriptor.json` самих схем (для схем из `conf/content` — `schemaUId` первого слоя, см. `client-schemas.md`).
5. «Обновить из файловой системы». Данные устанавливаются при установке пакета (`InstallType: 0`).

UId целевых таблиц (`Descriptor.Schema.UId` в `descriptor.json`): `SysModuleEntity` — `9c762665-90ad-497b-ac4b-45bb729630a1`, `SysModule` — `2b2ed767-0b4b-4a7b-9de2-d48e14a2c0c5`, `SysModuleEdit` — `24666f2d-049f-4867-ae2c-db681c40c001`, `SysDetail` — `363c2008-c733-407d-9b01-9e6a7cd9a77a`, `SysModuleInWorkplace` — `a8b20179-02be-4a13-8908-9fc51cb9f66d`.

## ✅ Новый раздел целиком
**Подтверждено** на разделе `TestColumns` (рабочее место «Студия»): 4 набора — `SysModuleEntity_SysModuleEntityManager_TestColumns`, `SysModule_SectionManager_TestColumns`, `SysModuleEdit_SysModuleEditManager_TestColumns`, `SysModuleInWorkplace_TestColumns` — склонированы с реальных наборов проекта с заменой значений по имени колонки; иконка `Image32` взята существующая (`09ce71be-b2bc-42ea-ab84-c47b12ebfe36`, Asset.svg). Раздел появился в меню, карточка открывается из реестра, по «Добавить» и по «+» в детали. Первая попытка упала из-за удалённого `DisplayValue` у lookup-ячеек (см. «Общий порядок»). После установки меню рабочего места может потребовать перезахода.

Порядок: объект (`entity-edit.md`) → карточка и раздел (`client-schemas-edit.md`) → регистрация:
1. `SysModuleEntity_SysModuleEntityManager_<Объект>`: `Id` = новый GUID (дальше — `<ME>`), `SysEntitySchemaUId` = UId объекта, `TypeColumnUId` = `"null"`.

   - `FolderMode` (✅ 06.10.2026, `TestTicket`): `b659d704-3955-e011-981f-00155d043204` «Включать запись в несколько групп» (86 разделов проекта, нужны объекты групп `<Объект>Folder`/`<Объект>InFolder`) или `a24a734d-3955-e011-981f-00155d043204` «Не использовать группы» — раздел без групп, объекты групп не нужны. `DisplayValue` ячейки — подпись режима.

4. `SysModuleInWorkplace_<Объект>`: `Id` = новый GUID, `SysModule` = `<M>`, `SysWorkplace` = UId рабочего места (спроси у пользователя, в какое рабочее место добавить), `Position`. Id рабочих мест в файлах проекта не хранятся: попроси пользователя выполнить `SELECT "Id", "Name" FROM "SysWorkplace"` и сверь имя в ответе с тем, что просили. ✅ Раздел в двух рабочих местах (08.10.2026) — вторая строка (`Row`) в том же наборе `SysModuleInWorkplace_<Объект>` и свежий `ModifiedOnUtc`.

## Удаление
Удалить папки Data-наборов регистрации вместе со схемами. Строки в таблицах БД при удалении набора сами не удаляются (см. `data-edit.md`) — их нужно удалить отдельно в CRM.
