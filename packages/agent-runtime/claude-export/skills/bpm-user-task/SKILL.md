# Своё действие процесса (пользовательская задача с C#)

Подскилл вызывается из `bpm-develop` (шаг 3, исследование) и при записи действия. Порядок работы, план и подтверждение — в `bpm-develop`. Правила стенда — в `CLAUDE.md`.

## Что читать (по порядку)

1. `.claude/skills/bpm-knowledge/metadata-editing.md` — общая механика записи, читай первым.
2. `.claude/skills/bpm-knowledge/user-task.md` — факты: параметры `FJ1`, файл `.cs`, вставка в процесс (`BL7`, `J6`, `BP2`, `GT4`/`GT5`).
3. `.claude/skills/bpm-knowledge/user-task-edit.md` — рецепты (✅): своё действие процесса с `.cs`, вставка в процесс, изменение, удаление и переименование параметров, удаление действия; асинхронное действие (`return false`, `CompleteExecuting`, `CancelExecuting`).
4. `.claude/skills/bpm-knowledge/templates/process/user-task-call.json` и папка `templates/process/user-task-schema/` — шаблон элемента «Выполнить действие процесса» и самого действия; бери, только если в проекте нет своего образца.
5. C#: `.claude/skills/bpm-knowledge/source-code.md`, `.claude/skills/bpm-knowledge/platform-api.md` (правило для C# — в `CLAUDE.md`: сначала `platform-api.md`, затем `BPMSoft.*.xml`, затем примеры в `Autogenerated/Src` и `Pkg`).

Для вставки действия в процесс читай также `process-edit.md` (раздел «Выполнить действие процесса») и `.claude/skills/bpm-knowledge/processes.md`, если нужна связь с процессом.

## Обязательные правила

- Не угадывай `using`, классы и методы платформы: проверяй по `BPMSoft.*.xml` и примерам.
- Тексты, которые видит пользователь, — локализуемые строки `ru-RU` и `en-US`.
- Переименование и удаление параметров — по рецепту из `user-task-edit.md`: ссылки в процессе тоже меняются.
- Удаление действия — разрушительная операция: проверь ссылки по UId и имени во всём `Pkg`, покажи пользователю и получи подтверждение.

## Обязательные шаги после записи

- Запусти `node .claude/skills/bpm-knowledge/scripts/pkg-lint.js BPMSoft.Configuration/Pkg/<Пакет>/Schemas/<Действие>` и, если менялся процесс, — также папку схемы процесса. Скрипт проверяет скобки в C# и структуру процесса. Исправь все строки «ОШИБКА» и повтори запуск.
- Перечитай изменённый `.cs` и `metadata.json`.

## Что сказать пользователю после записи

Нажать «Обновить из файловой системы» и выполнить компиляцию: код на C# меняется, поэтому компиляция обязательна. После компиляции — Ctrl+F5. Проверка: запустить процесс с этим действием и посмотреть результат по критериям приёмки.
