# Данные пакета BPMSoft

Подскилл вызывается из `bpm-develop` (шаг 3, исследование) и при записи данных. Порядок работы, план и подтверждение — в `bpm-develop`. Правила стенда — в `CLAUDE.md`.

## Что читать (по порядку)

1. `.claude/skills/bpm-knowledge/metadata-editing.md` — общая механика, `ModifiedOnUtc`, ресурсы.
2. `.claude/skills/bpm-knowledge/data.md` — факты: `descriptor.json`, `data.json`, `Localization`, `InstallType`, справочные колонки.
3. `.claude/skills/bpm-knowledge/data-edit.md` — рецепты (✅): системная настройка и её значение, записи справочника с переводом, набор для таблицы со справочными колонками, датами и числами, `IsForceUpdate`, `InstallType` при обновлении из файловой системы.
4. Шаблоны — `.claude/skills/bpm-knowledge/templates/README.md` и папка `templates/data/<таблица>/`: бери, если в проекте нет своего образца той же таблицы.

## Обязательные правила

- Данные пакета не удаляются при обновлении. Удаление записей — только SQL-скриптом пакета после подтверждения пользователя (см. `bpm-sql-script`).
- Идентификаторы записей (`Id` рабочих мест и т.п.), которых нет в `Pkg`, не угадывай. Для `Id` рабочего места попроси пользователя выполнить запрос и прислать результат, например: `SELECT "Id", "Name" FROM "SysWorkplace";`.
- Шаблон копируй в `BPMSoft.Configuration/Pkg/<Пакет>/Data/<Имя набора>/`; в `descriptor.json` — свой UId набора, `Name`, `ModifiedOnUtc`. Колонки (`Columns`) из шаблона не меняй. Остальные GUID в шаблоне — константы платформы, их не меняй.
- Значения, которые видит пользователь (подписи записей), — на `ru-RU` и `en-US`.
- Ссылки между записями — согласованными GUID.

## Обязательные шаги после записи

- Запусти `node .claude/skills/bpm-knowledge/scripts/pkg-lint.js BPMSoft.Configuration/Pkg/<Пакет>/Data/<Имя набора>` (для наборов данных — папка набора). Исправь все строки «ОШИБКА» и повтори запуск.
- Перечитай `data.json`, `descriptor.json` и ресурсы.

## Что сказать пользователю после записи

Нажать «Обновить из файловой системы». Компиляция для данных не нужна. Проверка: SQL-запрос, который покажет появившиеся записи или значение настройки, — готовым текстом.
