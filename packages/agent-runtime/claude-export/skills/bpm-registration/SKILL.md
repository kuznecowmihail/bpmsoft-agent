# Регистрация в интерфейсе: раздел, карточка, деталь, справочник

Подскилл вызывается из `bpm-develop` (шаг 3, исследование) и при записи регистрации. Порядок работы, план и подтверждение — в `bpm-develop`. Правила стенда — в `CLAUDE.md`.

## Что читать (по порядку)

1. `.claude/skills/bpm-knowledge/metadata-editing.md` — общая механика записи, читай первым.
2. `.claude/skills/bpm-knowledge/registration.md` — факты: `SysModule`, `SysModuleEntity`, `SysModuleEdit`, `SysModuleInWorkplace`, `SysDetail`.
3. `.claude/skills/bpm-knowledge/registration-edit.md` — рецепты (✅): регистрация нового раздела целиком, отдельной карточки и мини-карточки, детали, справочника в разделе «Справочники» (таблица `Lookup`); группы в разделе (`<Объект>Folder`/`<Объект>InFolder`, `FolderMode`, `UseStaticFolders`); карточки по типам (`TypeColumnUId`, `TypeColumnValue`, `ActionKindCaption`); новое рабочее место (`SysWorkplace`).
4. `.claude/skills/bpm-knowledge/templates/README.md` и папка `templates/data/` (наборы регистрации `SysModule*`, `SysDetail`, `Lookup`, `LookupRecords`, `SysImage`) — бери шаблон, если в проекте нет своего образца той же таблицы.
5. Для данных регистрации читай также `data.md` и `data-edit.md`, если нужны значения, не покрытые рецептом.

## Обязательные правила

- UId схем раздела, карточки, детали, объекта — из `Pkg` (свои схемы) или из `Autogenerated` (базовые). Не угадывай.
- Id рабочего места (`SysWorkplace`) — попроси пользователя выполнить запрос и прислать результат, например: `SELECT "Id", "Name" FROM "SysWorkplace";`.
- Новые GUID записей — генерируй; ссылки между наборами данных — согласованными GUID.
- Подписи разделов, карточек и кнопок — на `ru-RU` и `en-US`.
- Регистрация для карточки — и отдельное открытие, и совмещённый режим раздела; вариант «только в разделе» не предлагай.
- Удаление регистрации — разрушительная операция: проверь ссылки по UId во всём `Pkg`, покажи пользователю и получи подтверждение.

## Обязательные шаги после записи

- Запусти `node .claude/skills/bpm-knowledge/scripts/pkg-lint.js BPMSoft.Configuration/Pkg/<Пакет>/Data/<Набор>` для каждого изменённого набора и `.../Schemas/<Схема>` для изменённых схем. Исправь все строки «ОШИБКА» и повтори запуск.
- Перечитай изменённые `data.json`, `descriptor.json` и ресурсы.

## Что сказать пользователю после записи

Нажать «Обновить из файловой системы». Компиляция, как правило, не нужна. После обновления — Ctrl+F5, затем проверить, что раздел появился в меню системы или справочник в разделе «Справочники», и открыть карточку по критериям приёмки. Проверка записей регистрации — SQL-запрос готовым текстом.
