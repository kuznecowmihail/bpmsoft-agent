# Проверка интерфейса CRM в браузере

Скилл открывает CRM в браузере сессии и смотрит страницу: текст, консоль, сетевые запросы, снимок. Правила стенда — в `AGENTS.md`.

## Что нужно
- Инструменты браузера в сессии: в Claude Code — встроенный браузер приложения Claude или Claude in Chrome; в Cursor — его браузер (`cursor-ide-browser`: `browser_navigate`, `browser_snapshot`, `browser_cdp`). Браузера нет — отдай проверку пользователю списком шагов.
- Есть инструмент `crm_browser_login`. Нет — попроси пользователя войти в CRM в этом браузере самому и продолжай после его ответа.

## Вход — только так
1. Вызови `crm_browser_login` и прочитай ответ: адрес страницы входа и фрагмент JavaScript. Выдача пароля ждёт 120 с.
2. Открой в браузере ровно этот адрес. `localhost` и `127.0.0.1` — разные адреса: на другом пароль не отдаётся.
3. Выполни фрагмент в странице целиком, как напечатан: в Claude Code — инструментом выполнения JavaScript; в Cursor — `browser_cdp`, метод `Runtime.evaluate`, параметры `expression` (фрагмент), `awaitPromise: true`, `returnByValue: true`.
4. Ответ, который начинается с `200`, — вход выполнен; открывай нужную страницу. Сам порт из фрагмента не проверяй (`curl`, браузер): пароль отдаётся один раз и только странице CRM.

Запрещено: вводить логин и пароль в форму входа, подбирать пароль (`Supervisor` и другие), вызывать `AuthService` своим кодом, читать `.claude/*.local.json` и `ConnectionStrings.config`. Предупреждение страницы входа «BPMSoft не поддерживает работу в текущем браузере» вход не блокирует.

Не вышло со второй попытки (ответ не `200`, `crm_browser_login` ответил ошибкой или страница не забрала пароль) — остановись. Не перезагружай страницу по кругу: напиши, что видел, и попроси пользователя войти в CRM в этом браузере самому.

## Что смотреть
Адреса страниц, поиск элементов, шум в консоли и что проверять по типу правки — `.claude/skills/bpm-knowledge/browser-check.md`; имена инструментов браузера из знаний в нём — инструменты браузера твоей сессии (`AGENTS.md`, «Как читать знания»). Консоль и сеть: в Cursor — сначала `browser_cdp` с подпиской на ошибки или чтение уже собранных, затем загрузи страницу заново через `browser_navigate` на тот же адрес. `Page.reload` и другие методы `Page.*` через `browser_cdp` не вызывай: в Cursor они перезагружают всё окно редактора, а браузер возвращается на страницу входа.

В браузере только смотри: не сохраняй и не удаляй записи, клик — для навигации. В ответе процитируй увиденное: текст ошибки, файл, адрес запроса и код ответа.
